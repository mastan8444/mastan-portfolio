# Shaik Mastan Saheb — AI & Full-Stack Software Engineer Portfolio

Personal engineering portfolio showcasing production AI agents, cloud-native machine learning deployments, interactive system architecture case studies, certifications, and an integrated AI Copilot.

## Highlights

- **Autonomous Insurance Claim Pre-Assessment Agent**: Engineered using RAG, vector search, and LLM tool calling, reducing policy validation latency by **40%** with built-in AI guardrails and output evaluation.
- **AI-Powered PPT Generator**: FastAPI + `python-pptx` + Model Context Protocol (MCP) server pipeline automating editable slide deck generation (**80% effort saved**, **5× faster** assembly).
- **Iris ML API Deployment**: Containerized FastAPI + Scikit-learn inference API deployed via Docker, Azure Container Registry (ACR), and Azure Container Apps (ACA) ([Live API Docs](https://iris-deploy-mastan.onrender.com/docs)).
- **Fangs Entertainment Portal**: Responsive React.js gamified web portal with local state persistence (**+45%** interaction rate, **0.8s** first paint).

## Run Locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev
```

*(Optional)* Configure `GEMINI_API_KEY` in `.env` to enable live Gemini responses in the portfolio AI Copilot; otherwise the built-in local assistant responds automatically.
